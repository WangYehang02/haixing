## 参数来源与运行方式

**原生五图**使用各图既有的训练和推断参数。稳定版把标准化前的残差倍率和残差损失权重设为 1，使用几何极性校准，关闭末端同伴原型融合。既有数值的最初选择过程没有完整公开记录。条件流权重 `weight` 作用于生成速度，末端融合权重 `peer_prototype_weight` 作用于节点分数，这两个位置可单独控制。各图自动隐藏宽度已列在表中。

**外部二十图**在三个种子 0、1、2 上，用相同的 144 个候选逐图选择。6 种训练设置来自 3 种属性重构权重与 2 种隐藏宽度，24 种推断设置来自 3 种条件流权重、2 种积分步数、2 种原型投影系数和 2 种平滑权重。候选的筛选与排序使用模型输出和图结构；所有图均有合格候选。

1. 任一搜索种子的编码器塌缩时，剔除该训练设置下的全部推断候选。只有在各搜索种子及尾部比例上都有有效分数的候选进入排名。
2. 在规定的邻域平滑之后、几何极性校准之前，取分数最高的 1%、5%、10% 节点。对每个比例计算高分组与其余节点的均值差，除以两组样本方差之和的平方根（改进 CSM）。对同一比例先取三种子均值，再在候选间求百分位，最后对三个比例的百分位取平均。
3. 另算三个种子对的全节点 Spearman 秩相关均值，以及高分节点集合的机会校正重合度。后者对种子对和三个比例取平均，同分边界以分数相同的节点分摊剩余名额。将这两项分别换成合格候选中的百分位。
4. 三项百分位等权平均得到目标值 $Q$，选 $Q$ 最大的配置，完全同分时按配置编号排序。此处四项推断参数的最终值在 `inference`。外部训练时检测器内部的极性开关关闭，推断时对原始分数单独使用与原生图相同的几何极性规则。[CSM 论文公式（3）](https://link.springer.com/article/10.1007/s10618-025-01115-5#Sec20)

主结果的外部图沿用逐图选出的设置，采用稳定残差和上述五个种子，其中 0、1、2 也参与了历史选参。图构造及评估掩码固定，各种子复用同一图。带 extension、all relations、BOND 或 ARC 的行分别代表表中指定的图构造。

**五图的后续选参研究**使用单独的 168 项候选网格（含条件流权重为零的候选），选参种子为 10、11、12。文件列出复合 $Q$、最终分数 CSM 以及极性校准前 CSM 三种规则的选参结果、完整搜索范围和确认参数。原生五图主结果继续使用上表的发布配置。[后续选参研究配置](studies/native_selectors.json)
