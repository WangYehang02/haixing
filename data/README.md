# 图输入与评价标签

[25 个图版本的数据来源与预处理](SOURCES.md) 汇集上游发布位置、版本差异与转换示例。

[图清单](graphs.json) 给出论文中 25 个图版本的 ID、显示名、节点数、特征数、边条目数、评价节点数、正类数及原始文件 SHA-256。Amazon (extension)、BOND Amazon 和 Amazon (all relations) 是不同的图版本。YelpChi-RUR 与 YelpChi (all relations) 也单列。原生五图可以通过 PyGOD 加载，也可以显式传入 NPZ。

每张图用一个 `inputs/<id>.npz` 保存以下两个数组。

- `x` 为节点数乘特征数的节点属性矩阵。
- `edge_index` 为形状 `(2, E)` 的整型数组。第一行是源节点，第二行是目标节点。保留原图的节点排列、边顺序、自环和重复边。

标签单独保存为 `labels/<id>.npy`，每个节点一个值。1 表示异常，0 表示正常，−1 表示没有评价标签。训练和无监督选参只使用图与模型分数。计算 ROC-AUC 和 AP 时保留标签为 0 或 1 的节点。缺少标签的节点仍然参与图上的训练和评分。

[原生图与编码器签名](native_signatures.json) 记录原生图两种张量各自的 SHA-256，以及主结果所用编码器的种子、训练轮次和 SHA-256。图清单中的 NPZ 哈希指既有归档文件，重新压缩相同数组可能改变文件哈希。外部图入口的校验和输入约定见[外部运行说明](../external/README.md)。
