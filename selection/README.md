## 从节点预测选参

每张图放在单独目录，每个候选只有一个 `tNN_iNN.npz`。编号中的 `t` 是训练配置，`i` 是推断配置。目录中放全体预定候选。每个文件含下列数组，各候选的节点顺序和种子顺序须一致。

| 键 | 形状 | 内容 |
| --- | --- | --- |
| `seeds` | (种子数,) | 按行记录训练种子 |
| `collapsed` | (种子数,) | 布尔型，每个种子的训练编码器塌缩标记 |
| `raw` | (种子数, 节点数) | 连续骨干分数，已完成配置所指定的平滑，尚未进入几何极性模块 |
| `final` | (种子数, 节点数) | 完整模型的最终异常分数，仅 `csm-final` 必需 |

例如，在一个候选的三个训练种子都产生分数后，按以下方式封装。每行对应同一个种子，列对应相同的图节点。训练程序可直接提供这些数组。

```python
np.savez("search_scores/t05_i03.npz", seeds=search_seeds,
         collapsed=encoder_collapsed_by_seed, raw=raw_scores, final=final_scores)
```

```sh
python selection/select.py run q search_scores --seeds 0 1 2
python selection/select.py run csm-final native_scores --seeds 10 11 12
python selection/select.py run csm-raw native_scores --seeds 10 11 12
```

命令输出 JSON，包含胜者、每个合格候选的目标值以及排除原因。全体候选均不合格时命令报错。预先确定搜索种子、候选网格与尾部比例，锁定选择后再用评价标签计算 ROC-AUC 与 AP。

### 复合规则 Q

1. 取分数最高的 $k=\lfloor nq\rfloor$ 个节点以及其余所有节点，$q$ 分别为 1%、5%、10%，$n$ 为图节点数。计算两组均值之差除以两组样本方差之和的平方根，得到 AutoGAD 改进的 Contrast Score Margin（CSM）。每组至少两个节点。对每个 $q$ 先取种子平均 CSM，在本图合格候选内取百分位，再对三个百分位平均，记为 $C$。
2. 对种子两两配对，计算它们在相同节点上的 Spearman 秩相关，取均值。将这个均值在合格候选中转为百分位 $S$。
3. 对每一对种子及每个 $q$，估计高分集合交集占 $k$ 的比例 $o$。边界并列节点均分剩余名额，以两个种子成员权重的逐节点乘积之和计算交集。用 $(o-k/n)/(1-k/n)$ 扣除随机重叠的期望，对种子对与三个比例取均值，再转为百分位 $H$。
4. 选取 $Q=(C+S+H)/3$ 最大的配置。跨候选百分位用并列平均秩；仅一个合格候选时取 0.5。目标精确相同时取字典序最小的配置编号。20 图的各组均满足方差估计所需的节点数。

### 原生五图的两种 CSM 输入

`csm-final` 在冻结的几何极性模块输出上直接计算 CSM，`csm-raw` 在平滑后的原始分数上计算。两者都先在每个搜索种子上用固定 5% 的尾部计算，再最大化三个种子的算术平均。采用作者实现的样本方差（自由度 1），高分组与所有剩余节点比较。5% 是本实验共用的先验，不需要真实异常率。[AutoGAD 论文式（3）](https://doi.org/10.1007/s10618-025-01115-5) · [作者实现 CSTs.py](https://github.com/ZhongLIFR/AutoGAD2024/blob/78ad77c5366941d567eb3824901e63cf77e20cbf/CoLA/CSTs.py#L54-L77)

[原生五图 CSM 研究配置](native_csm_choices.json) 给出两种输入各自选中的参数、候选编号、$k$、合格数与平均 CSM。使用种子 0、1、2、3、42 确认时，最终分数 CSM 的五图宏平均 ROC-AUC 为 48.920%，原主表配置为 71.056%。本文件夹将该实验保留为选参结果。
